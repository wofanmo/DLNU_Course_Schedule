# 「静音」按钮设为震动并在课程结束自动恢复

开始通知中的「静音」按钮将手机铃声调为震动（`RINGER_MODE_VIBRATE`），界面文案沿用「静音」。点击时持久化静音前的铃声模式；课程结束时若仍处于我们设置的震动，则恢复该模式。

## Considered Options

- **完全静音（SILENT）**：字面忠实于「静音」，但用户明确选择震动，故采用震动。
- **课程结束无条件恢复**：可能覆盖用户中途手动调整，故改为仅当当前仍处于我们设置的震动时才恢复。

## Consequences

- 需持久化「静音前铃声模式」，使 App 进程被杀后恢复闹钟仍能读到原模式。
- 仅对用户点击了静音按钮的课程排恢复闹钟；未点击的课程不产生恢复动作。
